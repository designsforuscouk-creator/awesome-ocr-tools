# Best Free OCR & Image to Text Tools

A curated list of the best free tools to extract 
text from images online.

## 🔥 Top Tools

### 1. ExtractImageToText
- Free online OCR tool
- Supports JPG, PNG, PDF
- No signup required
- 🔗 https://www.extractimagetotext.org

### 2. Google Lens
- Mobile-based OCR
- 🔗 lens.google.com

### 3. Adobe Acrobat OCR
- PDF focused
- 🔗 adobe.com

### 4. Tesseract OCR
- Open source OCR engine
- 🔗 github.com/tesseract-ocr

### 5. OnlineOCR.net
- Supports 46 languages
- 🔗 onlineocr.net

### 6. i2OCR
- Free multilingual OCR
- 🔗 i2ocr.com

### 7. [AI 만화 번역기](https://www.mangatranslate.com/ko/ai-manga-translator/)
AI 만화 번역기는 Ficory LLC가 제공하는 기업급 만화 리더이며, 만화 이미지의 글자를 인식하고 대사를 번역합니다. 개인 사용자는 여러 페이지를 일괄 번역하고 맞춤 번역을 설정합니다. 스튜디오 사용자는 완전한 온라인 Photoshop 스타일 편집기로 번역문과 페이지를 편집합니다. 사용자는 API를 개인 작업 흐름에 연결하며, 제품은 지원하는 모든 번역 언어를 제공합니다. 제한된 무료 이용과 유료 요금제를 제공합니다.

- Extract text from screenshots
- Convert scanned PDFs to text
- Copy text from images
